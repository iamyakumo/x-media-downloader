媒体下载

支持 X / Twitter微信视频号抖音小红书

使用说明
  • 装到桌面：用 Safari 打开本页 → 点底部「分享」→「添加到主屏幕」，之后像 App 一样打开。
  • 存到相册：点「保存」，弹出分享面板后选「存储视频」或「存储图像」。如果第一次点没弹面板，按钮会变成「再点一次保存」，再点即可。
  • 保存失败时：点「打开原文件」，视频点播放器的分享按钮选「存储视频」；图片长按选「存储到照片」。
  • X 链接：支持 x.com、twitter.com、fxtwitter、vxtwitter、mobile.twitter.com、i/web/status 链接，或直接粘贴推文数字 ID。t.co 短链网页无法展开，请在 X 里用「复制链接」。
  • 视频号 / 抖音 / 小红书：依赖第三方聚合接口，可能偶尔失败；仅登录可见或私密内容无法解析；下载地址有时效，过期请重新解析。
  • 不支持：微博（接口不允许网页调用）、YouTube（无可用的免费接口）。
